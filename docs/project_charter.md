# 📜 프로젝트 헌장 및 연구 배경 (Project Charter & Background)

## 📌 1. 프로젝트 배경 및 문제의식 (Motivation)

### 1.1 소액 자본 운용자의 현실적 딜레마
* **정석 퀀트의 한계:** 
  * 분산 투자, 일봉/4시간봉 추세 추종, 모멘텀 등 정석적인 퀀트 전략은 우수한 MDD와 연 20~40%의 수익률을 목표로 하지만, **거래 빈도가 매우 낮고 시드가 소액일 경우 절대 수익금이 미미**하여 자본 형성 속도가 지나치게 느림.
* **갈증과 도전 과제:**
  * 소액 시드의 빠른 회전과 성장을 도모하기 위해 **고레버리지와 높은 거래 빈도**를 도입할 때, 실제로 어떤 수학적·통계적 현상이 발생하는지 냉정하게 검증할 필요성이 대두됨.

### 1.2 본 실험 프로젝트의 이중 목적 (Dual Value)
1. **🚀 업사이드 (Upside - 실전 발굴):**
   * 극단적 시장 조건(유동성 클라이맥스, 스위프 등)에서 높은 승률로 단기 기술적 반등을 포착하는 **실전용 고승률 스캘핑 전략 발굴**
2. **🛡️ 다운사이드 & 경계값 테스트 (Boundary Stress-Testing):**
   * 고레버리지, 과도한 진입 빈도, 타이트/루즈한 청산 설정이 계좌를 어떻게 파멸(Liquidation)로 이끄는지 미리 한계치를 체득함으로써, **본진의 정석 퀀트 프로젝트를 위한 견고한 리스크 관리 방파제 데이터 확보**

## 🎯 2. 전략 선정 4대 핵심 기준 (Core Criteria)

모든 실험 전략은 아래 4가지 상호 연계된 기준을 만족해야 합니다:

| 번호 | 핵심 기준 | 세부 내용 및 이유 |
| :---: | :--- | :--- |
| **1** | **거래 빈도 최적화** | **일평균 1~3회 (3m~15m 고강도 필터링 및 정밀 타점 스캘핑)**<br>• 3m/5m의 정밀한 바닥 진입 엣지(칼타점)를 활용하되, 극단치 필터를 통해 과도한 매매를 억제하여 하루 1~3회의 엄선된 기회만 포착<br>• 수수료/슬리피지 잠식을 방지하고 포지션 노출 시간을 최소화하는 최적 구간 |
| **2** | **레버리지 극대화** | **50배 (또는 20~50배 고레버리지)**<br>• 소액 시드의 폭발적인 복리 증식을 위해 격리 마진 기반 고레버리지 활용 |
| **3** | **초고승률 비대칭 구조** | **승률 90%+ 지향 (손익비 희생 감수)**<br>• 고레버리지 환경에서 노이즈 손절을 피하고, 진입 직후 확실한 기술적 반등(+0.2%~+0.5%)만 짧게 발라먹고 탈출 |
| **4** | **기관 퀀트 이론 기반** | **실제 기관/헤지펀드 유동성 모델 적용**<br>• 단순 보조지표 과매수/과매도가 아닌, 롤링 VWAP 편차, 유동성 풀 스위프, 오더플로우/미시구조 불균형 등 엣지 기반 로직 |

## ⚙️ 3. 기본 실험 환경 및 제약 사항 (Constraints)

* **대상 시장:** 바이낸스 암호화폐 선물 (`BTCUSDT` USDT-M Perpetual)
* **기본 타임프레임:** `3m` ~ `15m` (단일 봉 또는 멀티 타임프레임 연계)
* **마진 방식:** 격리 마진 (Isolated Margin)
* **청산 위험선:** 50배 레버리지 기준 진입가 대비 약 $\mp 1.6\%$ 도달 시 거래소 강제 청산 (유지증거금률 0.4% 적용)
* **수수료 현실화:** 메이커(지정가) 0.02% / 테이커(시장가) 0.05% 및 슬리피지 고려

## 📂 4. 프로젝트 아키텍처 및 작업 표준

```text
extreme_trading_experiments/
├── docs/           # 프로젝트 헌장, 전략 로그북, AI 제안 요약
├── data/           # 바이낸스 15분봉 및 시세 데이터 캐시
├── strategies/     # 실거래/백테스트 공용 순수 전략 모듈 (전략별 독립 파일)
├── experiments/    # 전략별 백테스트, 그리드 튜닝, 파라미터 민감도 연구
└── results/        # 생성된 차트 이미지(PNG) 및 검증 리포트
```

### 작업 표준 (Workflow Standard)
1. **전략 구현:** `strategies/stratXX_name.py`에 표준 인터페이스 기반으로 작성
2. **실험 및 튜닝:** `experiments/` 내에 백테스트 및 몬테카를로 시뮬레이션 스크립트 작성
3. **결과 저장:** 생성된 차트와 결과는 `results/charts/`로 저장
4. **로그북 등록:** 검증 완료 시 [`docs/strategies_logbook.md`](file:///e:/Devs/extreme_trading_experiments/docs/strategies_logbook.md)에 정량적 성과 및 코드 맵 공식 기록
